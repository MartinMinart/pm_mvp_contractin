# Process Mining MVP: закупки и контрактация (горнодобыча)

**Демо-проект** для портфолио: как построить Process Mining-платформу **без закупки Celonis**, используя открытые библиотеки (pm4py, pandas, Plotly) и внутреннюю LLM как оркестратор.

## Контекст

Кейс вдохновлён задачей **Центра компетенций (дочка ЕвроХим)**: построить центр компетенций по Process Mining на базе внутренней корпоративной LLM. Процесс — **закупки и контрактация** в горнодобывающем холдинге (ЗИП, инженерное согласование, таможня, HSE, логистика до карьера).

**Ключевая метрика для холдинга** — не просто длительность, а **стоимость простоя** (`downtime_cost_per_day`). Задержка ЗИП для экскаватора = миллионы рублей в день.

## Как запустить

```bash
# 1. Клонировать репозиторий
git clone https://github.com/MartinMinart/pm_mvp_contracting.git
cd pm_mvp_contracting

# 2. Установить зависимости
pip install -r requirements.txt

# 3. Сгенерировать данные (если ещё нет)
#    events.csv (~270 МБ) и cases.csv НЕ коммитятся в репозиторий.
#    Генератор детерминирован (SEED = 42) — результат воспроизводим.
python tools/generate_synthetic.py

# 4. Проверить лог
python tools/validate.py

# 5. Открыть ноутбук
jupyter notebook notebooks/01_pm4py_analysis.ipynb

# 6. Открыть сайт локально
# (открыть site/index.html в браузере)
```
