# Вкладки и дашборды MVP Process Mining

## Предложенные вкладки (актуально под текущую реализацию)
Текущие вкладки в UI: `Обзор` (Overview), `Карта процесса` (Process Map), `Узкие места` (Bottlenecks), `Варианты` (Variants).

## Дашборды по вкладкам

### 1) Обзор (Overview) — "Executive Dashboard"
**Цель:** За 30 секунд дать руководству ответ "масштаб проблемы, главные драйверы, что делать".

**Вопросы, на которые отвечает:**
- Сколько кейсов/событий за период? Каковы суммарные потери от простоя?
- Какова средняя/медиана/P90 длительность?
- Доля отмен/возвратов/импорта?
- Как меняется длительность по месяцам? Есть ли выбросы?
- По каким категориям/регионам/типам закупки больше всего потерь?

**Компоненты:**
| Блок | График/элемент | Источник |
|---|---|---|
| Executive Summary | headline + 3 драйвера + action | `overview.executive` |
| Фильтры (свёрнутые) | Категория/Регион/Тип закупки/Месяц старта | `by_*`, `monthly` |
| KPI-группы | Объём/Время/Качество | `kpi_groups` |
| Длительность по месяцам старта | Линейный график + коридор ±5%, подпись "разброс X дн = Y%" | `monthly` |
| Лучший/худший месяц | Карточки | `best_month/worst_month` |
| По категориям | Таблица (кейсы, ср.длит., Потери от простоя, ₽) | `by_category` (+срезы) |
| По регионам/типам закупки | Таблица | `by_region`, `by_procurement_type` (+парные срезы) |

**Макет (схематично), 1440×900:**
```
[Header: 60px]
[Executive Summary: 60-80px]
[Фильтры (details): 40px]
[KPI: 3 колонки 120px]
[График месяцев (2/3) | Лучший/худший (1/3): 300px]
[Таблица категории (1/2) | Таблица регион/тип (1/2): 200px]
```

### 2) Карта процесса (Process Map) — "Process Discovery & Path Analysis"
**Цель:** Понять реальный поток, частотность переходов, длительность ожиданий.

**Вопросы:**
- Как выглядит процесс от заявки до оплаты?
- Какие переходы самые частые/долгие?
- Как проходит конкретный топ-вариант или диапазон вариантов?
- Какие узлы самые нагруженные?

**Компоненты:**
| Блок | График/элемент | Источник |
|---|---|---|
| Переключатель режимов | DFG / Один вариант / Диапазон вариантов | UI |
| Фильтр по категории/шагам | Чипы + шаги с/по | `process_map`, `variant_paths` |
| DFG-граф | Scatter (узлы+линии) с русскими подписями | `process_map` |
| Переходы (топ) | Список переходов с длительностью | `process_map.edges` |
| Длительность переходов | Таблица (частота/уникальные/ср/медиана/P90) + селектор метрики | `process_map.edges` |

**Макет:**
```
[Тулбар категории + режимы: ~60px]
[Caption: ~20px]
[График DFG/flowchart (основной) | Список переходов (330px): ~560px]
[Таблица "Длительность переходов": ~200px]
```

### 3) Узкие места (Bottlenecks) — "Performance & Cost Impact"
**Цель:** Найти узкие места и их экономический эффект.

**Вопросы:**
- Какие активности дают наибольшее ожидание?
- Каков нормированный скор с учётом доли кейсов?
- Сколько потерь от простоя связано с этими узлами?
- Что исправлять в первую очередь?

**Компоненты:**
| Блок | График/элемент | Источник |
|---|---|---|
| Топ-3 | Карточки (активность, ожидание, потери) | `bottlenecks.bottlenecks` |
| График ожиданий | Горизонтальный бар-чарт (топ-10/все) | `bottlenecks.bottlenecks` |
| Таблица активностей | Топ-10 по умолчанию, "Показать все 24" с внутренним скроллом | `bottlenecks.bottlenecks` |
| Сортировка | По нормированному скору/сырому/ожиданию/потерям | UI |

**Макет:**
```
[Info-banner: 40px]
[Тулбар сортировка/кол-во: 40px]
[Топ-3 карточки: 80px]
[Бар-чарт (1/2) | Таблица (1/2), высота 400px]
```

### 4) Варианты (Variants) — "Standardization & Conformance"
**Цель:** Оценить вариативность и покрытие процесса.

**Вопросы:**
- Сколько вариантов нужно для покрытия X% кейсов?
- Какие самые частые пути?
- Где отклонения?
- Насколько "стандартизирован" процесс?

**Компоненты:**
| Блок | График/элемент | Источник |
|---|---|---|
| Кривая накопленного покрытия | Line+area с аннотацией "топ-10 = X%" | `variants.variants` |
| Подсказка про Executive summary | Текст (переехал на Обзор) | UI |
| Топ-10 вариантов | Таблица с превью пути, долей, ср.длительности | `variants.variants` |

**Макет:**
```
[Info-banner: 40px]
[Покрытие (1/2) | Подсказка (1/2), высота 400px]
[Таблица Топ-10 вариантов: ~400px с внутренним скроллом]
```
