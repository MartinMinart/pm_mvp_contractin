# Легенда, UX-правила, схематичный wireframe

## Легенда вкладок
| Вкладка | Иконка/суть | Аудитория | Приоритет |
|---|---|---|---|
| **Обзор** | Дом/дашборд руководителя | Генеральный/коммерческий/закупочный блок | Критичен |
| **Карта процесса** | Граф/путь | Процессный аналитик/руководитель закупок | Критичен |
| **Узкие места** | Треугольник/бар | Операционный/финансовый блок | Критичен |
| **Варианты** | Список/путь | Процессный аналитик | Высокий |

## Легенда элементов UI
| Элемент | Описание | Применение |
|---|---|---|
| **KPI-карточка** | Ключевой показатель с единицей/хинтом | Обзор |
| **DFG-узел** | Активность (размер ~ от кол-ва кейсов) | Карта процесса |
| **Линия перехода** | Переход между активностями (толщина/цифра = частота) | Карта процесса |
| **Возврат** | Пунктирная линия (Legal Review Completed -> Draft Contract Created) | Карта процесса |
| **Топ-3** | Карточки узких мест с ожиданием/потерями | Узкие места |
| **Бар-чарт ожиданий** | Горизонтальный бар по активности | Узкие места |
| **Кривая покрытия** | Накопленная доля кейсов по топ-N вариантов | Варианты |
| **Drill-down панель** | Боковая панель деталей узла/перехода | Все вкладки где кликабельно |

## Цветовая легенда (текущие токены)
| Назначение | Переменная | Назначение |
|---|---|---|
| Акцент | `--accent-color` | Основные действия/узлы |
| Старт | `--success` | Начало процесса |
| Конец/нейтраль | `--secondary`/`--muted` | Конец процесса |
| Узкое место | `--danger` | Критичные узлы |
| Возврат | пунктир/опасный цвет | Итерации |
| Фон/карточки | `--bg-surface` | Карточки |

## Рекомендации по UX
- **Обзор** — максимально лаконичный для руководства, все цифры в бизнес-единицах
- **Карта процесса** — фокус на путях и переходах, русские названия активностей
- **Узкие места** — "что и сколько стоит", приоритет по экономии
- **Варианты** — оценка стандартизации, без избыточного инсайта
- **Фильтры** — сворачиваемые, но с чипами активных фильтров
- **Drill-down** — быстрый доступ к деталям без переключения вкладок
