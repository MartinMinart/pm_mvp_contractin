# Легенда, элементы UI и схема экрана

**Статус:** актуализировано по `site/index.html`, `site/assets/app.js`, `site/assets/style.css`.
**Дата:** 2026-11-02.

Общие принципы (экран без скролла, фильтры внутри вкладок, сортировка по заголовку, CSS-переменные) — в `docs/wireframe.md`. Здесь — расшифровка элементов и легенд.

---

## 1. Легенда вкладок

| Вкладка | Суть | Основная аудитория |
|---|---|---|
| **Обзор** | Сводка: объём, сроки, качество, потери | Руководитель закупок, коммерческий блок |
| **Карта процесса** | Маршрут и переходы, режимы DFG/вариант/диапазон | Процессный аналитик, руководитель закупок |
| **Узкие места** | Рейтинг активностей по ожиданию и потерям | Операционный и финансовый блок |
| **Варианты** | Разнообразие маршрутов и покрытие | Процессный аналитик |

Иконок у вкладок нет — только текстовые подписи.

## 2. Элементы шапки

| Элемент | Как выглядит | Поведение |
|---|---|---|
| **Логотип** | Три цветные точки, соединённые линиями | Декоративный, не кликабельный |
| **Подзаголовок** | «Закупки и контрактация», после загрузки — «Демонстрационный MVP на синтетических данных · 50 000 кейсов · 1 094 474 событий · 12 месяцев» | Обновляется из `overview.json` |
| **Вкладки** | Текстовые кнопки, активная подсвечена | Клик или ←/→ с клавиатуры |
| **Executive / Analyst** | Сегментированный переключатель из двух кнопок | Меняет детализацию; сохраняется в `localStorage` (`pm-mode`) |
| **Переключатель темы** | Кнопка ☾ (светлая) / ☀ (тёмная) | Переключает `data-theme` на `<html>`; сохраняется в `localStorage` (`pm-theme`) |

### Что именно меняет режим

- **Executive** — скрывает `.analyst-only`; в Bottlenecks недоступен «Сырой скор».
- **Analyst** — показывает колонку «Кейсов» и строку «Итого топ-10» в Variants, «переходов на кейс» в топ-3 Bottlenecks, разрешает «Сырой скор».

Тема и режим применяются до загрузки данных, поэтому сохранённое состояние не «мигает» при открытии.

## 3. Базовые элементы

| Элемент | Описание | Где встречается |
|---|---|---|
| **KPI-карточка** | Крупное значение + подпись + вторичные метрики; в global-режиме — тренд и спарклайн | Обзор |
| **Мини-KPI** | Три небольшие карточки: события, средняя стоимость кейса, доля импорта | Обзор, только без фильтров |
| **Executive summary** | Заголовок, период, 3 драйвера, блок «Рекомендация» | Обзор |
| **Карточка топ-3** | Ранг, активность, ожидание, норм. скор, потери; в Analyst — «переходов на кейс» | Узкие места |
| **Чип** | Кнопка-фильтр (категория, «Таможня», режим карты) | Process Map |
| **Сегментированный переключатель** | Группа взаимоисключающих кнопок («Топ-10/Все», Executive/Analyst) | Шапка, Process Map, Bottlenecks |
| **Бейдж** | Маленькая серая подпись с числом/пояснением | Заголовки карточек и таблиц |
| **Пустое состояние** | Иконка ⛳ + текст «Для этого среза нет данных» + подсказка сбросить фильтр | Обзор, Process Map, Variants |
| **Статус-баннер** | Красная плашка ошибки загрузки JSON с инструкцией запустить локальный сервер | Появляется при сбое fetch |
| **Оверлей загрузки** | Спиннер + «Загрузка данных…» | При старте |
| **Сортировка** | Клик по `th`; стрелка ▲/▼; числовые значения парсятся с учётом «млн/млрд ₽» | Все таблицы |
| **Пагинация** | «1–5 из 28», кнопки ←/→ | Таблица переходов |

## 4. Легенда графа процесса

### 4.1. Узлы

| Обозначение | Значение |
|---|---|
| **Зелёная точка** | Старт (`Requisition Created`) |
| **Серая точка** | Конец (`Payment Made`) |
| **Красная точка** | Узкое место |
| **Синяя точка** | Обычная активность |
| **Размер узла** | Растёт от числа кейсов с этой активностью (в Cytoscape размер определяется подписью, в Plotly — √ от доли кейсов) |

### 4.2. Рёбра

| Обозначение | Значение |
|---|---|
| **Толщина** | Частота перехода |
| **Цвет** | Средняя длительность перехода |
| **Зелёный** | Быстрый переход |
| **Жёлтый** | Средний переход |
| **Красный** | Медленный переход |
| **Пунктир** | Возврат (следующая активность стоит в кейсе раньше текущей) |
| **Число на ребре** | Количество переходов (Cytoscape) |

Легенда задаёт единые пороги для Cytoscape-графа и Plotly-карты: **< 1 дн** — быстрый (зелёный), **1–4 дн** — средний (жёлтый), **> 4 дн** — медленный (красный).

Над легендой DFG выводится подпись: «Толщина — частота · Цвет — время (дн) · Число — переходы».

## 5. Drill-down панель

Выезжает справа, перекрывает часть контента, вкладку не меняет.

| Поле | Для ребра | Для узла |
|---|---|---|
| Заголовок | «А → Б» | Название активности |
| Подзаголовок | «Переход в графе процесса», признак возврата, выбранная категория | «Активность · тип», выбранная категория |
| Метрики | Переходов, уникальных кейсов, переходов на кейс, средняя, медиана, P90, следующий шаг | Кейсов с активностью, среднее ожидание, норм. скор, средняя позиция, входящие/исходящие переходы |
| Действие | Кнопка «Скопировать как текст» | Нет |
| Закрытие | × или Escape | × или Escape |

Важно: панель показывает **агрегаты**, а не список кейсов. Для режимов «Один вариант» и «Диапазон» панель показывает только название активности и число кейсов.

## 6. Схема экрана Process Map

```
┌───────────────────────────────┬──────────────────────────────────────────────┐
│ Граф переходов (Cytoscape)    │ [категории] [Таможня] [Без таможни]          │
│ [+][−][Fit] [раскладка ▼]     │ [Топ-10][Все 28]                             │
│                               │ [DFG][Один вариант][Диапазон] ШАГИ с/по      │
│                               │ ┌──────────────────────────────────────────┐ │
│                               │ │ Карта процесса (Plotly)                  │ │
│                               │ └──────────────────────────────────────────┘ │
│                               │ Легенда: старт/конец/узкое место/обычная/    │
│                               │ возврат · толщина/цвет                       │
│                               │ ┌──────────────────────────────────────────┐ │
│                               │ │ Длительность переходов · МЕТРИКА [▼]     │ │
│                               │ │ таблица + пагинация                      │ │
│                               │ └──────────────────────────────────────────┘ │
└───────────────────────────────┴──────────────────────────────────────────────┘
                         ↑ draggable-разделитель
```

## 7. Темы и доступность

- Светлая тема — значения по умолчанию в `:root`. Тёмная — переопределения в `html[data-theme="dark"]`.
- Все графики Plotly читают цвета из CSS-переменных, поэтому при смене темы перерисовываются.
- Cytoscape-граф использует собственные фиксированные цвета узлов/рёбер и тему напрямую не подхватывает.
- Интерактивные элементы имеют `aria-label`, вкладки — роли `tab`/`tabpanel`, активная вкладка получает `aria-selected`.
- Переключатель темы сообщает состояние через `aria-pressed` и меняет `aria-label`.
- Фокус после открытия drill-down переводится на кнопку закрытия; закрытие — по Escape.
